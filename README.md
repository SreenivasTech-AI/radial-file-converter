# Radial File Converter 🪐🔄

> **Clean Drag-and-Drop Document & Image Converter** — Convert between **Word, PDF, Images (PNG & JPG), and Text** with an intuitive, dynamic circular orbital wheel!

---

## 🎯 Streamlined Format Matrix

The converter focuses on the core everyday file formats:
- 📕 **PDF Document (`.pdf`)**
- 📄 **Microsoft Word (`.docx`)**
- 🖼️ **PNG Image (`.png`)**
- 📸 **JPG Image (`.jpg`)**
- 📝 **Clean Text (`.txt`)**

### 🔄 Dynamic Surrounding Options

| When You Drop | Surrounding Orbit Shows |
|---|---|
| 📄 **Word (`.docx`, `.doc`)** | 📕 **PDF** &bull; 🖼️ **PNG Image** &bull; 📸 **JPG Image** &bull; 📝 **Text File** |
| 📕 **PDF (`.pdf`)** | 📄 **Word** &bull; 🖼️ **PNG Image** &bull; 📸 **JPG Image** &bull; 📝 **Text File** |
| 🖼️ **Image (`.png`, `.jpg`)** | 📕 **PDF** &bull; 📄 **Word** &bull; 📸/🖼️ **JPG/PNG** &bull; 📝 **Text File** |
| 📝 **Text (`.txt`)** | 📕 **PDF** &bull; 📄 **Word** &bull; 🖼️ **PNG Image** &bull; 📸 **JPG Image** |

---

## 🚀 How to Use

1. **Open the App:** Navigate to [http://127.0.0.1:8000](http://127.0.0.1:8000).
2. **Drop Your File:**
   - Drop a **Word document** in the center &rarr; surrounding wheel displays **PDF**, **PNG**, **JPG**, and **Text**.
   - Or drop directly onto any surrounding format pod to convert immediately!
3. **Download:**
   - Files download automatically upon completion (toggleable).
   - Click the eye icon for an in-app live preview.
